# WhatsApp Hub — إدارة كل أرقام واتساب في مكان واحد

لوحة تحكم ويب عربية تجمع كل أرقامك ومنصات واتساب (عادي، بزنس، Cloud API) في صندوق وارد موحّد مع إمكانية الرد والإرسال من أي رقم.

## المميزات
- ربط عدد غير محدود من الأرقام عبر مسح QR (واتساب / واتساب بزنس).
- ربط أرقام **WhatsApp Business Cloud API** الرسمية من Meta.
- صندوق وارد موحّد لكل الأرقام، أو عرض محادثات رقم واحد.
- استقبال وإرسال الرسائل لحظيًا، مع حالة التسليم/القراءة.
- رسالة جديدة لأي رقم من أي حساب متصل.
- حفظ الجلسات محليًا؛ لا حاجة لإعادة المسح بعد إعادة التشغيل.
- إرسال واستقبال الصور والفيديو والصوت والملفات (سحب وإفلات أو لصق مباشرة).
- ردود جاهزة (قوالب): اكتب `/` في مربع الرسالة لاختيار رد، مع متغير `{name}` لاسم العميل.
- ردود تلقائية: كلمات مفتاحية، رسالة ترحيب لأول تواصل، ورسالة خارج أوقات الدوام — لكل الأرقام أو لرقم محدد.
- حماية بكلمة مرور (اختيارية).

## التشغيل
```bash
cd whatsapp-hub
cp .env.example .env      # عدّل ADMIN_PASSWORD
npm install
npm start
```
ثم افتح: http://localhost:3000

## إضافة رقم عبر QR
1. اضغط «+ إضافة رقم» واختر «ربط عبر QR».
2. من هاتفك: واتساب ← الأجهزة المرتبطة ← ربط جهاز ← امسح الرمز.

## إضافة رقم Cloud API (Meta)
1. من Meta for Developers خذ `Phone Number ID` و`Access Token` دائم.
2. أضف الحساب من اللوحة بنوع «Cloud API».
3. في إعدادات Webhooks في Meta ضع:
   - Callback URL: `https://<نطاقك>/webhooks/cloud`
   - Verify Token: نفس قيمة `META_VERIFY_TOKEN` في `.env`
   - واشترك في حقل `messages`.

## الردود الجاهزة والتلقائية
من زر ⚙️ أعلى القائمة الجانبية:
- **الردود الجاهزة:** عنوان + نص. في المحادثة اكتب `/` ثم جزءًا من العنوان، واختر بالأسهم ثم Enter.
- **الردود التلقائية:** 
  - *كلمة مفتاحية*: يرد عندما تحتوي رسالة العميل على إحدى الكلمات.
  - *ترحيب*: يرد على أول رسالة من العميل إن لم تردّ عليه خلال X ساعة.
  - *خارج الدوام*: يرد خلال الساعات المحددة فقط، مرة كل X ساعة لكل عميل.
  لا تعمل القواعد على المجموعات.

## النشر
يعمل على أي خادم Node.js 22+ (VPS / Railway / Render). يُحفظ كل شيء في مجلد `data/` — انسخه عند النقل.
يمكن تشغيله بشكل دائم عبر `pm2 start src/server.js --name whatsapp-hub`.
